# Skill: Problem analysis and evidence triage (analyze-evidence)
- Split information into three buckets: **explicit user goals and constraints**, **evidence actually observed through tools**, and **unknowns still to be confirmed**.
- Cite only file content, line numbers and digests returned by real tools. Never present inference or simulated data as verified fact.
- When authorized files are insufficient to locate the problem, list the missing context explicitly instead of guessing.
