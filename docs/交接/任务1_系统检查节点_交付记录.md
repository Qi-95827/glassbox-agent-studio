## 2. 设计与兼容

- 设计文档：[动态系统检查节点设计](../概要设计/重构_动态系统检查节点设计.md)。
- 检查节点不写 `workflow_attempts`、`agent_invocations`，不产生 `model_invocations` 或 `tool_invocations`；检查输入以来源标识和结果 SHA-256 记录，正文仍以原表为权威来源。
- 检查通过时，下游 Agent 的输入包含检查摘要，并在 `workflow_handoff_checks` 保存接收收据；检查失败/无法判定时运行 `BLOCKED`、停止原因 `CHECK_FAILED`、下游 `SKIPPED`。
- 未注册检查在写入计划前拒绝；数据库形状约束拒绝未知节点类型；旧 `plan_nodes` 记录默认按 `AGENT` 读取。
- 图摘要只对含检查节点的图切换到 `workflow-graph-v5`，Agent-only 计划继续使用原算法。含检查节点的计划不生成动态恢复边界。
- 模板 `workspace-analysis` v2 为新增版本；v1 历史计划与运行记录保持原样本，不回溯改写。
