## 5. 已知限制

- 仅支持一个受信模拟 Bug 与固定 `tests/test_*.py` unittest 入口。
- 重复判断是原文摘要，不是语义去重；不跨工作区合并。
- 分诊不接受人工覆盖；用户确认关闭仍需当前版本回归与有效审查。
- 逐用例解析依赖 unittest verbose 输出，多行 docstring 可能无法解析并阻断。
- 交付报告为生成时组合，不是跨数据库与 Git 的一致性快照。
