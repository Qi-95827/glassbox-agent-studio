## 2. 设计与兼容

- 设计文档：[动态只读工作区恢复设计](../概要设计/重构_动态只读工作区恢复设计.md)，包含完整支持矩阵。
- 纯文本边界继续使用 `workflow-checkpoint-v1` 摘要；只读工作区使用 `workflow-checkpoint-v2`，历史纯文本检查点算法不变。
- 版本证据来自实际工具调用，不依赖提示词或模型描述；恢复前重新读取授权文件并比较 SHA-256。
- 只读子运行不重复读取已复用分析，不重复调用其模型；系统检查在子运行重新执行，不创建 Agent 或模型调用。
- 工具次数、模型轮次、已用时间、限额和 Token 统计沿父链继承，不因恢复归零。
- 写入、Bug 修复、在途检查/工具、未知副作用和恢复子运行再次恢复保持拒绝。
