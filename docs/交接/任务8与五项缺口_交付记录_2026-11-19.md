## 1. 本轮业务条件

1. 需求、设计、代码、测试入口都由服务端规则选择执行模板；决策与理由随任务持久化，页面可在创建前查看。
2. 候选计划只能修改节点预算和依赖；节点身份、Agent 定义、系统检查、模板授权、工作区写入权限不可借调整扩大。候选须完整覆盖现有节点、依赖存在且无环、预算不超过运行上限，应用后仍须用户确认计划。
3. 既有文档、代码差异或测试成果只能从已结算运行接入；目标与来源任务版本、工作区授权和结果摘要必须一致，执行前再次核对。
4. 目录授权在创建时展开为有效文件，排除规则、`.git`、符号链接和工作区外路径不会进入授权；运行开始和每次工具调用前重新核对，撤权或文件删除后旧范围失效。
5. 数据集草稿可编辑，发布版本不可变；批次绑定实际版本、配置和预算；失败案例必须显式确认脱敏后录入草稿，结果保留运行入口。
6. 外部动作保存标识、审批、目标版本和请求摘要；对账只查询补证，不重放写操作；无法确认时保持待人工核对并保留每次核对历史。
7. 周期快照保存计划版本、事件位置、节点完成数、累计轮次/工具/耗时、工作区指纹和预算摘要；恢复前校验快照摘要、计划版本和运行限额，租约未过期时拒绝第二个恢复者，过期允许接管。
8. 费用硬预算按供应方价格版本的输入/输出 Token 上界在派发前预留；完成后按实际用量结算；额度不足在模型调用前停止；未知用量保留预留并计为未知调用。

## 6. 未验证与限制

- 代码入口的模拟模型只读取授权文件，不实际写入，因此“代码入口模型产出的代码差异”仍未产生；本轮已用真实工作区差异和来源写入证据验证差异选择、字面路径、未授权文件拒绝、接入后撤权、只读测试接续与预览隐藏。实际差异提交/审查沿用任务 4 的 Git 用例。
- 测试入口已能接收授权范围内代码差异并实际运行只读测试证据工作流，但仍没有真实测试执行记录；不能把说明表述为测试通过。
- 计划编辑器已支持预算和依赖调整，但节点新增/删除、并行和更复杂的图重排仍不在本轮范围。
- 需求/设计入口在声明写入时沿用授权修改模板；这不代表需求/设计文档已获批准或测试已完成。
- 数据集失败案例录入要求用户手工确认脱敏；页面只提供运行标识和确认框，不含逐字段预览编辑。
- 外部动作只使用隔离内存适配器演练，没有接入真实 Issue/平台；真实平台查询语义、凭据和限流未验证。
- 周期快照每个已结算工作流边界保存，不是独立定时采样；租约演练仍为同一应用实例，跨进程故障演练未补；非动态工作流的历史运行没有快照，仍沿用既有兼容检查点。
- 费用价格默认为模拟模型零价；真实 DeepSeek 价格需用户发布价格版本，未核对供应方账单。硬预算在派发前校验输入字节上界并收紧 `maxTokens`/`maxCompletionTokens`；实际用量仍以供应方回执为准，超支会持久化到账本后停止后续调用。恢复子运行已验证继承剩余额度并零模型调用。
- 新页面已通过前端构建与既有测试；`Task8PageAcceptanceIntegrationTest` 从 HTTP 任务创建、成果接入、计划确认到运行详情走通一条链路。真实浏览器已核对规则路由弹窗和执行流程图/扩展面板，但未完成“接入按钮 → 运行详情”的完整浏览器点击链。
- 目录授权撤销已提供服务端 API 和执行页按钮；符号链接相关用例因 Windows 当前用户无创建权限而跳过，代码在目录展开和路径解析中拒绝符号链接，但本机未执行该分支。

## 7. 复现入口

1. 新建任务选择四类入口之一，创建前查看“规则路由”卡片和入口约定。
2. 勾选“先审阅计划再运行”，在计划视图调整节点预算/依赖，保存候选后查看差异并应用，再确认计划。
3. 工作区任务填写目录授权和排除规则；页面显示有效文件数，运行后执行页显示授权范围与快照。
4. 评测中心使用“可管理评测数据集”编辑、发布并运行批次；失败案例输入 runId、确认脱敏后录入。
5. 执行页可查看外部动作、周期快照、恢复租约、费用估算和价格版本；对账按钮只查询补证。
