# 持久化统一迁移 · 批次 3（工作区与 Git）交付记录

> 日期：2026-11-19。依据 [Spring Data JPA 持久化迁移范本](../开发规范/SpringDataJPA持久化迁移范本.md) 第 3–5 节和批次 1 交付记录。本记录只覆盖工作区、审批、Git 提交/交付和人工接手，不包含批次 2 的 Store 及其 Repository。

## 1. 本批入口与结构

| 原入口 | 迁移后 |
| --- | --- |
| `workspace/WorkspaceService`（`workspaces`、`workspace_declared_files`） | `WorkspaceRepository`、`WorkspaceDeclaredFileRepository` |
| `workspace/ApprovalService`（`approvals`） | `ApprovalRepository` |
| `workspace/GitDeliveryService`（`git_delivery_requests`、`git_actions`） | `GitDeliveryRequestRepository`、`GitActionRepository` |
| `workspace/WorkspaceCommitService`（`git_actions`） | `GitActionRepository` |
| `workspace/RunHandoverService`（`run_handovers` 及在途动作统计） | `RunHandoverRepository` |

新增实体：`WorkspaceEntity`、`WorkspaceDeclaredFileEntity`、`ApprovalEntity`、`GitActionEntity`、`GitDeliveryRequestEntity`、`RunHandoverEntity`，均位于 `persistence.entity`。

新增 Repository：`WorkspaceRepository`、`WorkspaceDeclaredFileRepository`、`ApprovalRepository`、`GitActionRepository`、`GitDeliveryRequestRepository`、`RunHandoverRepository`，均位于 `persistence.repository`。

## 2. 删除的旧路径

- 五个 Service 不再注入 `JdbcTemplate`，删除全部 `db.query`、`db.queryForObject`、`db.queryForList`、`db.queryForMap`、`db.update` 调用。
- 删除工作区声明文件的 H2 `MERGE ... KEY`、`INSERT INTO workspaces`、`INSERT INTO approvals`、`INSERT INTO git_actions`、`INSERT INTO git_delivery_requests`、`INSERT INTO run_handovers` 以及对应 `UPDATE/DELETE` 语句。
- 人工接手的在途动作统计改为 JPQL 计数（模型调用、工具调用、系统检查），不再拼接三表 SQL。
- `RunHandoverService` 的交还更新保留原 `COALESCE(?, note)` 语义，改为加载实体后仅在有新说明时覆盖。

## 3. 查询与写入方式

- 工作区列表、审批列表、Git 动作列表和交付请求列表使用派生方法排序；`workspaces`、`approvals`、`git_actions`、`git_delivery_requests` 的创建实体实现 `Persistable`，业务预分配主键时走插入路径，重复主键由数据库拒绝，不会静默覆盖旧行。
- `workspace_declared_files` 使用 `(workspace_id, path)` 复合主键；保存使用合并语义，同一路径再次声明时更新摘要、来源和时间，原有 `MERGE` 行为保留。
- 删除单个声明文件使用 `@Modifying` JPQL；补充文件路径并发创建仍由 `Files.write(..., CREATE_NEW)` 保证至多一个成功，声明入库失败只删除本次创建的文件。
- 审批过期、Git 动作结算、启动时未结算动作转 UNKNOWN、交付状态和结果更新使用带条件的 `@Modifying` JPQL。
- 工作区、审批、Git 和人工接手的列表读取不经过 JPA 关联加载，避免开放式会话和额外查询。

## 6. 保留的原生查询

本批没有保留 `nativeQuery=true`、`createNativeQuery` 或数据库特定 SQL。`MERGE` 已由 JPA 合并语义替代；列表排序、状态更新和计数均为派生方法或 JPQL。
