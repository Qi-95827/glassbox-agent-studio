# 持久化统一迁移 · 批次 4-5（Bug 与评测）交付记录

> 日期：2026-11-19。依据 [Spring Data JPA 持久化迁移范本](../开发规范/SpringDataJPA持久化迁移范本.md) 第 4 节批次 4-5。当前工作区同时包含其他批次尚未提交的迁移，本记录只覆盖本批。

## 1. 本批入口与结构

| 原入口 | 迁移后 |
| --- | --- |
| `bug/BugService` | `BugCheckRepository`、`BugCheckCaseRepository`、`BugFeedbackRepository` |
| `bug/BugIntakeService` | `BugIntakeRepository`、`BugRunSummary` 投影 |
| `evaluation/EvaluationRepository` | `EvaluationBatchRepository`、`EvaluationCaseRepository`、`EvaluationCheckRepository` |
| `evaluation/EvaluationSuiteService` | `EvaluationSuiteVersionRepository` |
| `evaluation/BugEvidenceAssessmentService` | `BugCheckRepository`、`BugTaskOwner` 投影 |

新增实体位于 `persistence/entity`：

- `BugCheckEntity`、`BugCheckCaseEntity`、`BugIntakeEntity`、`BugFeedbackEntity`
- `EvaluationBatchEntity`、`EvaluationSuiteVersionEntity`、`EvaluationCaseEntity`、`EvaluationCheckEntity`

新增 Repository 与查询投影位于 `persistence/repository`：

- `BugCheckRepository`、`BugCheckCaseRepository`、`BugIntakeRepository`、`BugFeedbackRepository`
- `EvaluationBatchRepository`、`EvaluationSuiteVersionRepository`、`EvaluationCaseRepository`、`EvaluationCheckRepository`
- `BugRunSummary`、`BugTaskOwner`

Service 保留原公开方法、返回字段名（Bug 检测和反馈仍返回大写列名 Map）、排序和异常类型。`BugIntakeService` 的 `record/triage/regression` 与 `EvaluationRepository` 的批次/案例写入由服务层事务管理，断言与案例状态在同一事务提交。

## 2. 移除的旧路径

- 五个类中不再注入或调用 `JdbcTemplate`，不再拼接表名和 SQL。
- Bug 检测、逐用例结果、原始描述、反馈、评测批次、套件版本、样本和断言全部改走实体与 Repository。
- 预分配主键的实体实现 `Persistable`，创建路径使用插入语义，重复主键由数据库拒绝，不会静默覆盖旧行。
- 分批读取逐用例证据和断言，避免按检测/案例逐行重复查询。

## 3. 查询与写入方式

- 常规列表和过滤使用派生查询；复杂归属核对、运行摘要和跨表读取使用 Repository 内 JPQL 构造投影。
- 状态条件更新（启动样本、关联运行、结算案例、提前结束批次、取消请求、分诊/回归回写）使用带条件的 `@Modifying` JPQL，并按受影响行数判定成功或冲突。
- 检测和逐用例证据、案例状态和全部断言分别在同一事务写入；断言先刷新，约束失败时整体回滚。
- 套件版本实体标记为不可变，只新增和读取，不提供更新路径；批次继续保存定义快照、`suite_version`、实际 `config_json` 与摘要。
- 预算比较逻辑未改：仍以 `config_json` 中的实际限制判断可比性，预算不同保持不可比。
- 工作区指纹逻辑未改：检测执行前后比对指纹，工作区变化时结果仍标记为 `STALE`；交付视图仍区分旧版本证据。

## 4. 保留的原生查询及理由

本批**没有保留** `nativeQuery=true`、`createNativeQuery` 或数据库特定 SQL。跨表归属查询使用 Hibernate 6 JPQL 实体连接（例如运行与任务），仍由 Repository 承载并在 H2 上验证。日期、CLOB 和空值按实体映射处理，未引入方言相关函数。
