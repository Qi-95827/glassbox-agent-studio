## backend\modules\control\README.md

# backend\modules\control

预算、限额、取消与错误控制。

当前单进程实现位于 `src/main/java/dev/workbench/control`：`RunControl` 维护一次运行的计数、暂停检查、预算与调用记录；`StopExecution` 表示受控停止。暂停／取消信号和调度仍由编排层管理，尚不支持跨进程限额预留或分布式取消。具体边界见 `docs/概要设计/首期_运行控制模块拆分设计.md`。

## backend\modules\evaluation\README.md

# 评测模块

本模块执行本地固定模拟种子集，保存批次、案例、运行关联和逐项断言，支持协作式取消、中断及历史批次对照。当前 V2 覆盖正常协作、工具失败、工具预算拒绝和重复工具调用保护；断言与案例结果事务保存，定义快照不同的批次不会被判断为可比较。

另提供对模拟 Bug 本次观察及当前代码版本回归记录的只读证据评估；这不等于已经证明真实 Bug 修复。用户管理的数据集、真实修复独立评测、完整代码和环境快照及统计报告仍待实现。
