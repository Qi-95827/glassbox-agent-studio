# 动态工作流重构验证

本轮验证覆盖同定义多节点、双前置汇合、角色权限上限、审批前无调用、累计预算、取消及认领回执失败的事务回滚。恢复验证覆盖已结算边界、跨运行来源、已报告用量继承、结果被修改和边界后已认领时的拒绝。使用隔离旧 H2 文件副本核对角色、依赖和预算数据，并验证同一迁移执行两次和按迁移前文件恢复。[详细设计](../概要设计/重构_动态工作流计划迁移与顺序调度设计.md)

系统检查节点的验证覆盖：只读模板中检查通过后下游获得检查结论和独立接收收据、无读取证据时检查失败并阻塞下游、重复认领被拒绝、检查记录写入失败时节点与检查记录整体回滚、未注册检查在写入计划前拒绝、旧角色计划节点按 Agent 类型读取。检查节点不产生 Agent 实例、模型或工具调用。[系统检查节点设计](../概要设计/重构_动态系统检查节点设计.md)
