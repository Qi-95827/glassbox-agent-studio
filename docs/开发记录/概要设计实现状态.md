# Agent 内部概要设计实现状态

> 更新于 2026-11-17。此表按当前代码和验证记录维护；“基础”表示只实现了明确列出的局部，不表示概要设计全部完成。历史版本计划仍见迭代计划目录。

| 设计方向 | 已实现并验证的基础 | 仍需完成的主要能力 |
| --- | --- | --- |
| 多入口与任务契约 | 本地任务目标、约束、待验证验收条件和用户选择的需求／设计／代码／测试／Bug 入口类型，模拟 Bug、工作区与预算参数。 | 自动意图识别、各入口完整产物流程、缺信息交互、验收证据自动判定和任务版本。 |
| 规划与多 Agent | 只读任务两个 AgentScope 实例，写授权任务增加独立开发 Agent；固定计划有依赖与权限校验、角色工具能力交集、版本化交接和事务记录；任务图依赖以节点 ID 持久化，支持多前置校验与就绪计算及按节点认领。受信版本化 Agent 定义已接入 AgentScope；新计划记录定义 ID、版本和定义／技能声明摘要，运行时核验并单独记录。 | 公开任务流程和预算仍绑定旧角色；新定义还不能由任务图自由引用。摘要不覆盖工具实现、模型行为或完整上下文，完整装配快照未完成。相同角色多节点、通用 DAG 执行、模型规划、并行／重试等仍未完成。 |
| Tool / Skill | 模拟检查、授权文件读取、字面搜索和写入工具；统一成功及可纠正拒绝结果、用户授权和调用限额；按角色装配内置 Skill 并记录版本与摘要；工具通过可信提供者注册，记录成功装配和调用版本。 | 动态工具类型与数据库迁移、自动强制扩展工具使用网关、未知异常结构化分类、工具版本发布与兼容治理、外部 Skill 导入发布、未知副作用对账。 |
| 记忆与上下文 | 任务契约、用户确认工作区背景和 Bug 观察按上下文来源有序装配；背景有版本历史、低可信装配及按工作区、类别和内容检索，记录运行装配引用并检查数量和顺序；AgentScope 独立会话及框架 JDBC 状态持久化。 | 会话恢复与周期一致性快照、可验证压缩、模型候选审核、语义／模糊检索、撤权传播和检索评测。 |
| 运行控制与预算 | 运行总时长、模型轮次、工具总次数、统一及按工具类型的单工具限额、统一单 Agent 及按角色配置的单实例模型／工具调用限额；已报告 Token 响应后停止阈值；可选连续相同工具调用保护；暂停、取消、终态保护及结构化停止原因；已启动 Agent 的停止状态、事件与系统交接事务保存。 | 严格 Token／费用硬预算、并发原子预留、语义无进展检测、策略化重试和跨进程取消。 |
| Checkpoint | 启动前、无工作区及受限只读工作区的分析完成后安全边界；审查前可连续恢复，继承预算并验证历史来源及适用的工作区状态；分析后检查点未生成时记录结构化原因并提供低基数监控指标。 | 周期快照、框架会话与系统状态协同恢复、写入工作区／Bug 恢复及外部动作对账、租约与分布式一致性。 |
| 工作区、Git 与 Bug | 显式授权最多 20 个现有文件读写与范围内字面搜索；工作台可查找 Git 已跟踪文件并逐项加入授权；独立 worktree、模拟 Bug 观察与容器回归按运行及代码状态关联证据、审查、用户主动本地提交。 | 目录授权、仓库级或正则搜索与新建文件、更多语言、真实 Bug 源、不可复现分诊、未跟踪文件审查、用户授权推送与合并。 |
| 评测 | 四类固定模拟种子（含重复调用保护）及事务保存的逐项断言、运行追溯、协作式取消、带定义快照校验的历史批次逐案例对照；对本次模拟 Bug 观察和当前代码版本回归做只读证据评估；临时仓库与 Docker 的独立自动测试。 | 可管理版本化数据集、真实修复独立评测、复杂故障样本、代码及完整环境快照和统计报告。 |
| 观测与后台 | Agent 耗时与用量、分工具调用统计、事件游标、本地聚合页面、Prometheus 格式出口；复用现有 Prometheus 抓取及 Grafana 独立看板。 | 持续告警、分布式链路、运营控制及完整审计；共享看板尚无租户隔离。 |
| 身份与安全 | 本机回环监听、来源校验、显式文件集合授权、代码版本审查、部分容器资源限制。 | 认证、项目与租户授权隔离、密钥治理、可信沙箱、系统化注入／越权评测。 |
| 用户交互 | 运行轨迹、审查、工作区、评测、基础监控、记忆、本地提交，以及不含自由文本的精简报告。 | 动态计划调整、补充信息与接手、完整报告自动脱敏、前端视觉专项、完整后台交互。 |

最新测试、真实模型调用和已知限制以 [开发记录](开发记录.md) 为准；源码目录中的 README 也应与实际能力同步。
# 补充：通用工作流声明（重构中）

已建立按节点标识、Agent 定义引用和依赖分离的工作流声明，并让现有固定计划通过它校验和保存。声明本身可表达多个节点引用相同定义，但旧数据库及执行器仍限制同一运行中的角色唯一；动态节点执行、节点级交接和恢复尚未实现。详见《重构首批_通用工作流声明与旧计划适配》。
