# 任务 3 目标现象匹配关卡设计

> 承接[产品开发与验收交接](../交接/动态Agent重构后_产品开发与验收交接.md)任务 3。状态为已实现首个关卡（2026-11-19），交付证据见[任务 3 阶段交付记录](../交接/任务3_目标现象匹配关卡_交付记录_2026-11-19.md)；后续逐用例、分诊与交付见[分诊与交付设计](任务3_分诊与交付设计.md)。

## 1. 范围

任务 3 要求先记录模拟 Bug 的来源、版本和预期失败现象，再以目标现象而不是“任意测试失败”判定复现。本期交付：

- 模拟 Bug 定义增加 `source`、`version`、`expectedSymptom`、`expectedTestId`、`expectedFailureText`。
- 复现检查解析 unittest 逐用例结果：只有**完整目标用例自身**失败且断言包含预期文本，才视为 `FAILURES_OBSERVED`；混合失败、相似名称、目标未执行或被跳过分别记为 `TARGET_MISMATCH`、`TARGET_NOT_EXECUTED`、`TARGET_SKIPPED`，阻断下游。
- 回归检查要求目标用例实际执行且结果为 `PASSED`；整体通过但目标被跳过时不得报告修复。
- 检查证据保存 Bug 来源、版本、预期现象、逐用例结果和容器实际输出；流程图显示未匹配原因。
- 未匹配时定位、修复、回归和审查节点全部未执行，模型、工具（含写入）调用为零。

## 2. 判定口径

| 容器结果 | 判定 | 下游 |
| --- | --- | --- |
| 未发现测试（exit 3 / TESTS_DISCOVERED=0） | `NEEDS_INFO` | 阻塞；复用任务 2 补充请求 |
| 测试全部通过（exit 0） | `NOT_REPRODUCED` | 阻塞；不可进入修复 |
| 目标用例自身失败且断言行完整等于 `AssertionError: 1 != 3` | `FAILURES_OBSERVED` | 允许进入定位与授权修复 |
| 目标用例失败但断言不同（如 `1 != 30`），或只有其他用例出现预期断言 | `TARGET_MISMATCH` | 阻塞；明确显示未复现目标现象 |
| 没有完整目标用例（含相似名称） | `TARGET_NOT_EXECUTED` | 阻塞；相似名称不能替代 |
| 目标用例被跳过 | `TARGET_SKIPPED` | 阻塞；回归时也不得报告修复 |
| 环境、超时、中断、代码版本变化 | `ERROR`/`TIMEOUT`/`INTERRUPTED`/`STALE` | 阻塞 |

- 目标现象由受信模拟 Bug 定义提供，不接受模型或测试文件自行声明；目标用例按完整标识精确匹配。
- 证据绑定容器实际输出、逐用例结果与工作区指纹；`TARGET_MISMATCH`/`TARGET_NOT_EXECUTED`/`TARGET_SKIPPED` 不生成补充请求（补充测试不能改变目标现象定义）。

## 3. 展示

- 流程图：复现检查显示“失败”，阻塞面板显示“测试存在失败，但未出现模拟 Bug 的目标现象”，未启动下游逐项列出。
- 节点详情：检查摘要、Bug 来源/版本、预期失败测试与断言、容器实际输出。
- 页面“本次 Bug 检测证据”始终显示目标现象定义；检测记录状态使用中文标签（含“未匹配目标现象”）。

## 4. 验收样本

| 样本 | 仓库（合成） | 预期 | 实际 |
| --- | --- | --- | --- |
| 目标匹配 | `calculator.py` 为 `a-b`；`tests/test_calc.py::test_add` 断言 3 | 复现通过，允许定位/修复/回归，终态等待用户核对 | deepseek-flash 运行 5 节点完成，任务等待核对 |
| 仅无关失败 | `calculator.py` 为 `a+b`；`tests/test_other.py::test_other` 断言 `2+2==5` | `TARGET_NOT_EXECUTED`，修复节点未执行，写入零 | 复现检查失败，下游全部未执行，0 模型/0 工具 |

模拟回归同时覆盖 Docker 直接检查与完整工作流；真实验收仅使用隔离数据库、临时合成仓库和 1 次 deepseek-flash 运行。
