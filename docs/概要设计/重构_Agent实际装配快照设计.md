# Agent 实际装配快照设计

快照在 AgentScope 实例创建成功、模型首次调用之前写入。记录版本化定义和摘要、已选模型名称及配置版本、AgentScope 执行参数、已加载技能、已注册工具、权限配置、实际使用的预算策略、输入上下文来源与摘要。工作区文件范围只保存摘要和数量，提示、模型输入、工具参数、凭据与文件正文均不进入快照。旧数据缺少完整快照时展示未记录。

上下文贡献者标出实际纳入的任务、授权记忆版本和 Bug 检查引用。固定流程的后续节点记录已交接的交接标识，动态节点记录实际接收的上游尝试和当前节点。快照使用项目生成的版本和受信模型适配器提供的公开模型标识。摘要标识装配输入，无从据此判断模型实际消费、执行结论或资源隔离。

快照与兼容查询依赖的定义、技能、工具授权在同一事务保存，并核对认领的计划定义。写入失败时 Agent 不调用模型或工具。运行详情允许按实例读取版本化快照。验收覆盖正常动态及原角色流程、不同实例和输入来源的关联、缺少快照的历史读取、快照写入失败时兼容记录的回滚和零模型调用。
