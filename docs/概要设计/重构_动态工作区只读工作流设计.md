# 动态工作区只读工作流设计

在新建工作区任务时开放「授权文件分析」模板。第一个节点使用受信只读分析定义，按过往工作区工具约定读取或搜索任务授权文件。汇总节点只有文本能力，通过直接依赖取得上游分析和已完成工具调用引用。模拟路径验证实际工作区读取；汇总只报告根据资料得出的分析及待验证项。

工作流版本记录权限类型与授权范围摘要，节点显式标记是否可访问工作区。创建、确认和节点认领使用同一授权校验。只读型任务必须选择已有工作区和授权文件，服务端拒绝写入、项目背景记忆和 Bug 选项与本模板组合。工作区路径由授权摘要和工具各自的路径校验约束。旧纯文本图继续使用原摘要格式；动态工作区模板暂未定义可恢复边界。

认领事务校验上游节点、尝试和实例的归属及完成状态。只有该直接上游实际成功的授权读取或搜索调用可作为交接引用。回执及工具引用一起保存，汇总输入只包含分析及引用元数据。引用证明所列工具调用已结算，不代表历史文件内容仍为当前版本或任务验收已完成。

验收验证计划确认前零调用、单文件及多文件授权、汇总节点无工作区权限、交接包含实际调用引用、鉴权范围变化后拒绝执行，以及原纯文本与兼容入口的回归。
