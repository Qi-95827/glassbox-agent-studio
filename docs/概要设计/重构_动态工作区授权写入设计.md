# 动态工作区授权写入设计

「分析、修改与审查」复用既有的授权工作区和写入开关。保存的计划依次包含只读分析、授权修改和独立审查节点。计划和授权摘要绑定模板的只读或写入策略；只有明确声明写入工具的修改节点获得写权限，且路径限定为现有授权文件。修改仍使用从读取获得的 SHA-256，并由工作区服务确认版本。审查节点依据交接及实际调用引用运行，自身无工作区工具。

只有已结算的实际写入调用可进入写入证据。汇合事务绑定回执和证据；结果未知时停止，保留受控状态，供人工核对，不继续调度审查。流程结束后的工作区差异和验收由用户检查，运行进入待处理。当前模板不提供写入后自动恢复。

验证使用隔离工作区。测试注入确定性模型驱动读取、条件写入和审查，核对实际文件版本、原仓库、越权文件和各节点权限。缺少显式写授权、模拟模型未修改、以及写入结果未知分别走既定的拒绝或待核对状态。既有纯文本和只读计划保持原摘要版本。
