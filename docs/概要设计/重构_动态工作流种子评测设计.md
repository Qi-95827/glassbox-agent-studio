# 动态工作流种子评测设计

评测中心增加固定的动态工作流套件，使用模拟模型运行两个“双视角分析”样本。正常样本核对计划、独立实例、前置关系、实际模型调用和双来源回执。限额样本用两轮共享总预算，核对模型调用停止、两个上游完成、汇总未完成和限额原因。

每个批次保存套件代码、版本、模板及样本断言定义。原 LOCAL_AGENT_V2 快照与默认入口保持兼容；不同套件和不同定义快照不可作回归比较。评测只是读取受控运行结果，模型文本不作为独立实例、证据或效果的断言依据。当前动态样本验证纯文本链路，工作区和恢复继续使用其隔离集成用例。

验收从真实评测 API 创建批次，检查两个样本均关联实际运行，逐项断言通过，并核对原有默认入口及异套件比较的行为。
