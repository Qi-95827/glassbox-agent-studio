# 动态计划节点预算设计

创建动态任务时可按模板节点键为模型和工具调用分别设置上限。空值沿用运行现有策略；工具上限为 0 时不启动该节点的工具调用。节点费用、Token 及时间仍由现有运行策略控制。设置随节点写入不可变计划并参与图摘要，既有无节点预算的计划保持原摘要结构。恢复副本继承原节点设置。

调度器将持久化节点标识和限额绑定给当前实例。运行控制器在开始调用前，叠加运行总预算、单实例、角色、工具和节点预算。节点用量依据该节点所有尝试关联的实际调用记录，失败的已启动调用也计入。达到节点限额时记录明确原因，下游不继续。实际装配快照和工作台展示生效的节点限额。

验收验证已保存预算、多节点使用同一定义时限额仍分别生效、节点超限停止调用而运行总预算仍有余量、旧计划及已有恢复链兼容。
