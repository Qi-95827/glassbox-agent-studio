# AgentScope 工具强制网关设计

## 注册与授权

工具提供者是受信 Java 配置，只接收只读的任务工具范围，包括工作区标识、授权路径和场景。它返回稳定工具名称、描述、参数、校验、业务动作及展示摘要的声明。提供者不能通过此契约取得 Toolkit、AgentRuntime 或自定义 AgentScope 工具对象。

装配器产生授权工具类型与版本后，注册表核验服务端版本及唯一工具名称，只将项目生成的工具包装器注册至 AgentScope。类型、版本、读写性质来自服务端策略，业务提供者不能覆盖。首批保留现有模拟检查、授权文件读、搜索和写入，包括单文件与多文件版本。

## 调用与结果

包装器执行每次模型工具调用。它按参数声明生成 Schema，根据服务端前缀和稳定参数顺序计算摘要，并进入 ToolGateway。网关执行实例权限、版本、调用预算及取消检查。通过后校验参数形状和授权路径，执行具体动作，统一记录调用、结果和耗时。SDK 直接拒绝的无效请求不会执行任何动作。兼容现有工具名、参数、计算摘要的字段顺序、结果 JSON 和历史记录。

预算拒绝与取消在业务动作前传播。输入或文件版本错误维持结构化拒绝。写入动作开始后的异常、执行中断或结果持久化失败按副作用未知处理，文件版本冲突只在确知尚未写入时归为可纠正拒绝。工具动作仍需遵守工作区服务的实际范围与版本约束。受信代码装配工厂只构造声明，Java 插件的进程隔离和强制终止仍单独处理。

## 验收

同一轮后端回归验证注册版本和名称冲突，验证通过注册包装器执行的工具在预算拒绝时未进入业务动作，参数不合法时未触发实际调用，成功结果与运行实例账本一致。验证现有不授权文件、文件版本冲突、未知写入结果、AgentScope 模拟工具和工作区流程。
