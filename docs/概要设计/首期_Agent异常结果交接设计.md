# 首期 Agent 异常结果交接设计

Agent 已实际启动但未正常返回时，由协调器根据运行控制结果记录结构化结果交接，区分失败、取消、预算超限和中断。交接发送方为实际 Agent 角色，接收方为协调器；来源标记 `SYSTEM`，说明它是系统观测而非模型回答。交接包含目标、用户约束、受控停止说明和已记录的成功工具证据引用，明确未完成或未知，不伪造 Agent 输出，也不启动依赖该结果的后续角色。

运行和 Agent 调用的终态仍是权威记录；失败交接作为补充记录，使用版本化交接、来源与证据校验。常规异常对用户只显示安全的类别说明，不直接返回异常原文或外部服务响应，避免泄露密钥、文件路径或提示内容；预算和取消等系统控制消息保留明确原因。异常详情的受控诊断和审计后续单独设计。

本期交接与运行终态、工具调用并不在同一个完整事务内，突然宕机或数据库异常可能只有终态而没有交接；启动时标记中断的历史调用不会自动伪造交接。验收覆盖分析失败、开发预算不足、审查预算不足及取消，确认已完成的上游状态保留、未执行的下游不显示成功、交接状态和来源准确。
