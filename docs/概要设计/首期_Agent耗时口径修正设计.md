# Agent 耗时口径修正设计

## 问题

Agent 历史表只有创建和更新的墙钟时间，没有保存单调计时器时长。此前对所有非运行中状态直接相减；中断记录可能在进程重启后才被标记，差值包含停机时间，不能当作准确的 Agent 耗时。运行中、异常旧状态、损坏时间和系统时钟回拨也不能计算可靠时长。

## 规则

仅明确以 COMPLETED、FAILED、CANCELLED、LIMITED 正常落终态的 Agent，用记录的更新时间减创建时间计算墙钟区间；该值可能包含暂停、调度与其他等待，也受系统时钟调整影响，并非纯模型执行时间。RUNNING、INTERRUPTED、未知状态、时间无效或结果为负的情况返回 null，界面显示未知。模型与工具调用采用现有已记录的单调时钟毫秒值，仍分别显示缺失数量；不通过 Agent 墙钟耗时推导各调用耗时或百分位。

现有字段保留以兼容 API，工作台与报告标明墙钟口径。未来要获得可跨进程累计的有效执行时长，需额外设计状态持久化、暂停和单调时钟恢复，不由本改动声称实现。验收覆盖正常、运行中、中断、未知状态、非法时间和时钟回拨。
