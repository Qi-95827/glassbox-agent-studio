# Agent 装配计划设计

## 装配流程

1. 验证角色定义的身份、版本和职责，以及用户提供的工作区与授权文件数量；无工作区不能授予写入。
2. 按角色技能清单读取已经校验的内置技能，按角色工具上限与任务授权求交集。
3. 依据授权文件数量确定工具契约版本：单文件读写版本 1，多文件读写版本 2；模拟检查版本 1。输出不可变的角色定义、技能和工具版本计划。
4. 执行器根据该计划向 AgentScope 实际注册工具，并比较实际注册集合及版本；不一致时拒绝继续。成功装配及后续调用仍分别记录，装配计划本身不证明工具调用成功。

## 权限与边界

技能方法只提供指导，不增加工具权限。预算、模型包装、会话存储和事件记录仍由现有运行控制与 AgentScope 集成提供；本期没有把这些能力做成可自由启停的插件。角色仍是服务端内置的固定角色，尚不支持模型或用户动态创建 Agent、自由编排通用 DAG 或热更新配置。
