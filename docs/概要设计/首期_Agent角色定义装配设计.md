# Agent 角色定义装配设计

## 目的

将受控的角色定义集中到注册表：角色名称、版本、系统指导与声明工具一起构成一个不可变定义。AgentScope 执行器和只读角色目录使用同一个注册表，减少两套定义产生偏差。

## 校验与装配

- 启动时检查所有内置角色均有定义，定义的角色身份及版本与键一致；名称、指导、版本和工具集合必须有效。注册表及工具集合复制后不可修改。
- 执行时从注册表取角色定义，与用户给定工作区及写入授权求交集，再注册实际工具；技能由独立技能目录和角色清单装配，预算和运行记录由控制模块提供。
- 角色目录展示的是声明的能力，不代表任务已经授予该能力，具体装配和实际调用仍以运行记录为准。

## 边界

目前定义仍由服务端内置代码维护，角色枚举和固定流程没有变；不支持用户或模型动态注册角色、自由组合运行模块、通用多 Agent 任务图或热更新。引入新角色还需要实现其流程、权限、交接和评测。
