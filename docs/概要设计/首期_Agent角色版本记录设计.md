# 首期 Agent 角色版本记录设计

Agent 角色编码与版本由服务端维护，分析、开发、审查角色初始版本均为 1；当职责、系统提示词或工具能力发生有意义的行为变更时，需更新相应版本并记录变更。创建每个 Agent 调用时，随实例记录受控角色编码和版本；工作台可展示角色版本，模型和工具调用仍通过 Agent 实例 ID 关联。

角色定义从同一角色枚举获取版本，避免展示版本与实际装配版本分离。历史数据库新增字段允许为空，旧记录展示“未记录”，不推测或回填真实版本。当前仅记录版本号，没有保存不可变配置快照、提示词摘要、模型版本组合或自动变更检测，不能据此保证历史运行可完整重放；未来版本治理需补充这些能力。

验收覆盖各角色实际调用记录的编码／版本、旧记录迁移保留空值、角色装配与记录来源一致，及现有多 Agent 和检查点回归。
