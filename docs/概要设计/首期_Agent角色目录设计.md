# Agent 角色目录设计

## 目标

面向学习和排查展示当前内置角色、职责提示、声明的工具能力、技能方法、版本与技能内容摘要。目录从实际运行使用的角色定义和技能注册表读取，避免另维护一份可能过时的说明。

## 授权边界

目录展示的是角色声明的能力上限，不代表任意任务都能使用；运行时仍由角色声明、工作区、用户写入授权和调用限额共同决定。页面可同时查看运行详情中的实际工具装配和调用记录；声明、成功装配、实际调用和任务结果是不同事实。

当前只有内置分析、开发和审查角色，使用固定顺序计划。该目录只读，不创建或修改 Agent，不提供动态组件注册、通用 DAG、租户治理或发布审批。提示词和技能方法的展示不证明模型遵循；历史运行的角色版本和技能摘要仍应以历史记录为准。
