# 首期 Agent 角色能力装配设计

将角色的名称、版本、系统职责和工具能力集合集中定义，并在创建 AgentScope `ReActAgent` 时按集合装配工具；分析角色具备模拟检查与授权文件读取能力，开发角色具备授权文件读取及写入能力，审查角色没有工具。角色能力只是上限，不是授权：工作区不存在时不注册文件工具，未显式授权写入时不注册写工具，已有服务端路径、文件版本、预算及取消检查继续生效。

能力采用系统维护的枚举，角色定义和版本由代码固定；不从模型或请求中读取任意系统提示词和工具权限。新增角色需先扩充受控角色枚举与角色定义，并由编排流程明确调度；该期不是动态角色管理、自动规划、任意插件或并行多 Agent。已发生运行的角色版本持久化和历史配置回放仍待后续实现。

验收通过固定角色定义的能力集合测试，覆盖无工作区、只读、显式写入、审查无工具和错误授权；运行模拟模型、实际文件读取及预算回归验证 AgentScope 实例仍通过原有调用链执行。
