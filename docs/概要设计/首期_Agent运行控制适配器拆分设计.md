# Agent 运行控制适配器拆分设计

## 目的

将 AgentScope 调用过程中与项目运行控制交互的职责，从任务编排服务中的匿名对象拆成独立适配器。编排服务负责选择运行和 Agent 实例；适配器负责向控制模块及记录仓储转发模型、工具、技能和事件。

## 约束

- 模型调用前检查预算并登记；响应后记录用量，再检查已报告 Token 阈值。
- 技能、工具装配记录由仓储保存；只有成功登记后才允许同一 Agent 按登记的类型和版本发起工具调用。
- 未登记工具、版本不符、登记失败均不得进入工具调用；工具结果和可纠正拒绝分别记录状态。
- 检查暂停、取消、时间及调用次数继续由运行控制模块负责；适配器不自行授予权限，不把工具结束视为可恢复的系统检查点。

本次仅调整现有职责位置和可测试性，不改变用户接口、固定角色流程或 AgentScope 语义；不引入动态编排或新的恢复能力。
