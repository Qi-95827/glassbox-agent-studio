# 首期 Prometheus 监控出口设计

使用 Spring Boot Actuator 与 Micrometer 暴露本地 `/actuator/health` 和 `/actuator/prometheus`，沿用工作台的 127.0.0.1:8088，不创建 Grafana 实例，不修改已有 Prometheus／Grafana 配置。进程、JVM 等由框架公开；业务指标以数据库当前记录为来源，提供按固定状态分类的运行数、Agent／模型／工具调用数、种子评测样本数、已知 Token 合计及未知用量次数、已知耗时合计及耗时未知次数。

业务指标是数据库快照 gauge，历史记录状态可改变或被未来保留策略删除，不能当作只增 counter；已知 Token 求和在没有已知用量时为 0，但同时暴露已知调用数和未知调用数，不能把它解读为完整用量为零。耗时以秒为单位，不包含未记录时长；未构造分布，不能计算 P95。标签限定为状态、调用类别和输入／输出方向等有限值，绝不包含任务、运行、用户、文件、提示词或密钥。

接口只供可信本机使用，不构成认证或租户隔离。容器内 Prometheus 是否能访问仅监听回环的工作台取决于网络配置，不能为了抓取而直接把服务暴露公网；实际接入、数据源、看板和告警需按部署环境单独验证。数据库不可用或抓取失败应在监控层显示失败，不应视为零。验收检查指标名称、标签、数值与数据库一致、已知／未知区分、无高基数标识，并通过集成测试验证端点暴露；已有 Grafana 环境未接通时如实标记未验证。
