# 首期 Agent 交接契约校验设计

新增交接契约版本 `1` 和 UUID 交接 ID，生成后同一对象既持久化也序列化给接收 Agent，数据库记录 ID 与交接 ID 一致。旧记录没有版本和 ID 时保留为空，不编造历史数据；未知版本不得作为新交接写入。

写入前确定性校验任务／运行／Agent 标识、运行所属任务、角色方向、状态、接收实例和必需文本。证据引用必须提供来源运行，事件必须确实属于该运行且为工具结束事件；不允许重复事件或跨运行伪造引用。恢复到审查的流程可引用已校验的原运行分析实例和原运行证据；其他实例必须属于本运行。接收实例在交接记录生成时可能尚未启动，故本期只校验其 UUID 与目标角色，不声称已经接收或完成。

相同交接 ID、方向及内容重复写入按幂等处理；同 ID 不同内容或方向拒绝。该保证限单机 H2 表，不能替代跨服务消息去重、接收确认、租户授权、证据语义核验或事务性投递。历史记录继续可读；新交接与旧字段兼容。验收覆盖新版本和 ID、来源与事件归属、非法方向、重复写入、冲突拒绝、历史 JSON 读取和两／三角色真实执行路径。
