# 首期任务约束与验收契约设计

在现有目标、工具授权和预算之外，允许用户分别填写任务约束和验收条件，各最多 10 条，每条 1—300 字。字段以结构化列表持久化，旧任务默认空列表；创建前验证类型、长度和条数，拒绝超限而不是静默截断。用户输入不授予工具权限，也不能覆盖系统安全规则；验收条件是待检验要求，不等于系统已经验证。

将约束和验收条件以带标签 JSON 传入分析 Agent，并在协调者委派及分析到审查的交接中保留；模型看到的是用户要求，不得将模型输出作为验收通过证据。当前仍无自动从需求推导完整契约、多轮澄清、版本修改和自动判定验收；没有填写条件不自动补造。

验收覆盖输入边界、旧数据兼容、目标与约束持久化、实际交接传递、无约束任务和用户界面；真实模型只是理解要求的辅助，安全校验由系统执行。
