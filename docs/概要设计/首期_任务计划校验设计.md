# 首期任务计划校验设计

当前由服务端根据写入授权生成固定计划：只读为分析 → 审查，授权写入为分析 → 开发 → 审查。生成结果使用明确的计划节点与依赖类型，在落库前经独立校验器检查：节点和角色完整且不重复、依赖存在且不自指、依赖图无环、开发角色必须与写入授权一致。

现有执行器和数据库只支持两个或三个固定顺序节点、每个节点最多一个前置节点，因此校验器还必须拒绝超出当前执行器能力的拓扑；不能因为无环就宣称任意 DAG 已可执行。验证失败时运行和计划创建事务回滚，不启动 Agent。计划是待执行声明；实际执行及其证据仍以调用和事件记录为准。

该期不让模型生成或自行授权计划，也不实现动态调度、并行、节点重试或用户调整。验收包括正确两种计划、重复节点、缺失依赖、循环、越权开发、不支持的拓扑及现有多 Agent 工作流。
