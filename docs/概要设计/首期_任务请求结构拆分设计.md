# 任务请求结构拆分设计

将任务创建请求从运行编排服务的嵌套类型拆成独立的 `CreateTaskRequest`。请求字段、JSON 名称、默认值处理、入参校验与任务调度行为不改变；HTTP 接口仍接受同样的请求体。控制器、评测和测试统一使用新类型，领域状态与持久化模型保持独立。

现有短参数构造方法暂时保留在新类型中，以支持已有的内部调用；这些重载不是推荐给未来模块的长期扩展方式，后续应按输入场景引入清晰的工厂或构建器，并保持 HTTP 契约兼容。内部 Java 类型名称从 `RunService.CreateRequest` 改为 `CreateTaskRequest`；项目尚未发布公共 Java SDK，外部直接调用旧类型的源码需要适配。
