# 首期内置技能装配与追溯设计

Skill 是角色执行方法和注意事项，不是工具授权。本期提供代码内维护的三个只读内置技能：问题分析、受限代码修改、证据审查，分别装配给分析、开发、审查 Agent。每项包含固定编码、版本、名称和方法文本，计算文本 SHA-256；AgentScope 创建实例时把对应方法加入角色系统提示，同时记录实例、技能编码、版本和摘要，供工作台查看。

技能注册由服务端根据角色确定，模型不能添加、修改或选择额外工具；实际工具仍取角色能力与用户授权交集。记录表示技能说明已装配，不证明模型遵循了每一步，也不代表测试或操作已发生。因为角色提示内容变化，三个角色版本从 1 升为 2；历史调用及其版本不回填，旧调用没有技能记录。

本期不支持上传第三方 Skill、在线编辑、自动触发、沙箱脚本、完整 Git 发布流程或基于 Skill 内容自动授予权限；内置技能修改时需提升版本、更新测试和开发记录。验收覆盖按角色装配、稳定摘要、真实 Agent 调用绑定、旧记录兼容、只读／写权限不被技能文本扩大和两／三角色回归。
