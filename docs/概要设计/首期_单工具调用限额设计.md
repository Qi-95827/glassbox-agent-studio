# 首期单工具调用限额设计

在已有运行总工具次数、模型轮次和时限之上，增加“每一种工具最多调用次数”。本地任务可选择 0—20；未提供时默认等于总工具上限，不改变旧调用方行为。工具类型使用系统控制的枚举，映射到现有调用记录名称，不能由模型任意指定或修改限额。

每次执行前按运行及其恢复祖先的调用记录统计同种工具次数，成功、失败和已启动但结果未知均计入；达到限额时不启动新调用，运行标记超限。总工具预算和单工具预算同时生效，恢复运行继承上限并累计祖先记录，不因角色切换或恢复而重置。旧数据库迁移默认上限 20，旧调用者默认按总上限设置；运行详情展示这项限制。当前仅单进程顺序协调，检查与调用记录不是分布式原子预留，不能用于多实例并发保障；记录写入失败、分布式租约和未知副作用对账需后续设计。

验收覆盖单工具上限为零时不启动工具、总预算仍然生效、历史调用计数按工具分类、恢复沿祖先累加、非法上限拒绝以及旧任务兼容。Mock 模型只使用一种工具，跨多种真实工具的模型自主调用不在本次验收中。
