# 受控停止事务

运行失败、用户取消、预算超限或中断时，将仍在执行的 Agent 终态、计划结算、运行状态及结构化停止原因、停止事件和系统交接一起保存。没有启动 Agent 时不伪造交接。状态和原因由枚举决定；交接必须属于同一运行、同一 Agent，且由系统产生。事务任一步失败均回滚这部分记录，不能把未知处理结果写成成功。

在途模型／工具调用结束记录仍由运行控制器在此事务之前单独更新；它们可能已发生外部副作用，也可能因异常而结果未知。数据库故障时本事务可能无法写入，进程重启后由现有中断处理标识未完成运行；这不是对外部请求的回滚，也不提供跨进程一致性。

排队运行收到取消时，取消请求事件单独记录；状态、USER_CANCELLED 原因、计划结算和取消事件在停止事务中提交。执行队列明确拒绝普通新运行时，记录 FAILED／UNCLASSIFIED_FAILURE 和失败事件，不伪造 Agent 调用。恢复运行派发拒绝仍沿用其专门的安全重试状态。
