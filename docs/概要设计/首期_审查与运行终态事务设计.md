# 审查结果与运行终态事务

## 目标

审查 Agent 成功后，将审查节点与调用完成、结果交接、运行终态及相应事件放进同一数据库事务，避免崩溃时出现审查已完成而运行仍在执行，或运行已完成但审查结果没有保存。

## 规则

仅当前 RUNNING 运行中正在执行的审查 Agent 可提交；终态更新使用状态条件，暂停或已终止时拒绝；校验 Agent、运行、结果交接归属和摘要。运行结果只能是 COMPLETED 或需要用户处理的 BLOCKED，后者必须包含原因。最终暂停／取消检查仍在单进程协调锁内进行。事务任一步失败均回滚，已在外部执行的模型或工具调用不在回滚范围内。

## 边界

事务只覆盖本地数据库，不保证模型调用、外部写入或进程异常的恰好一次；异常后的运行可能被标记中断。分析和开发 Agent 的结果已分别与其完成状态共同提交，但整个多 Agent 流程并非一个长事务。
