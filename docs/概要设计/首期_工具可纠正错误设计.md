# 首期工具可纠正错误设计

工具结果契约升级为版本 `2`：成功包含 `SUCCEEDED` 与 `data`；仅对明确在目标写入前拒绝的参数错误和文件版本冲突，返回 `REJECTED` 与结构化安全错误（编码、说明、需要修正后才能再次尝试），不返回原始异常或敏感路径。版本冲突要求重新读取授权文件；错误不能授予额外工具权限。每次被拒绝的调用仍计入工具及运行预算，模型是否再次尝试由 AgentScope 和已有轮次／次数限制约束。

预算、取消和超时由控制层异常终止运行，不转换成可忽略的普通工具结果；其他可能涉及外部副作用或结果未知的异常继续终止当前运行，不伪装成确定失败或自动重试。服务端为写入前的哈希不匹配提供独立类型，避免将所有 `IllegalStateException` 错误地归为可安全重试。工具拒绝记录为实际调用失败并产生 `TOOL_REJECTED` 事件，不作为成功工具证据。

验收覆盖成功和拒绝的版本化结构、调用 ID、参数错误、版本冲突、预算异常与未知异常不被吞掉、失败调用计数、现有真实／模拟流程。该期仍缺少外部动作 UNKNOWN 台账、通用 Schema、自动退避和模型错误修正质量评测。
