# 首期已报告 Token 预算设计

任务可选设置一次运行及其恢复祖先的“已报告 Token 上限”，单位为 Token，范围 1—1,000,000；不设置则沿用现有轮次、工具与时长限制。模型调用完成后，先保存供应商实际返回的输入和输出 Token，再累加本运行和所有恢复祖先中已报告的用量；达到或超过上限时停止后续执行。每次新模型调用前也复核预算，跨角色、重试和恢复不能清零。

如果任一已启动模型调用的输入或输出用量未知，启用预算的运行在收到结果后停止并标记超限／不可继续，不把未知写成零；恢复也不能绕过该未知状态。失败或中断请求可能已产生费用，若无可获得用量同样视为未知。未启用此项时保留既有未知用量行为。

这是**供应商响应后的已报告用量停止阈值，不是严格预付费硬上限**：请求发出前无法准确知道输入和输出 Token；单次请求可以使实际消耗超过阈值，供应商可能收费但没有返回用量。当前不估算费用、不做并发原子预留，也不承诺跨进程限额。旧任务默认不启用，恢复继承原值。验收覆盖默认兼容、未知用量停止、已知用量相加、祖先累计、参数边界及结果真实记录。
