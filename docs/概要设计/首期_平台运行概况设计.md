# 首期平台运行概况设计

单机个人版增加只读运行概况：按受控状态统计运行、Agent、模型、工具及评测案例；汇总模型已知输入／输出 Token、未知用量调用数，以及模型／工具已知耗时和未知耗时调用数。数据按读取时数据库中的所有保留记录计算，非时间窗口指标、不是计费账单，也不表示共享部署具备管理员权限。

工作台提供独立入口，展示当前统计口径和明确的未知量；页面只显示低敏聚合数据，不展示提示词、代码或凭证。详情仍通过运行视图访问。Prometheus 与此处复用同一批持久化记录但可能在不同时间采样，短暂差异不代表精确同步。服务不可用时显示错误，不把缺失值改成零。当前仅本地单用户环境，无登录、审计管理操作、实时告警、跨租户隔离或分布式链路。

验收覆盖空数据库的零计数、模拟运行后的分类统计、模型用量未知、HTTP 查询及前端实际查看；不得以已知用量代替完整总量。
