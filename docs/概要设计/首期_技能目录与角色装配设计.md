# 技能目录与角色装配设计

## 目的

将技能定义和角色技能清单分开：技能目录按受控编码保存不可变定义，角色清单按顺序引用技能编码，装配时解析为具体方法及其版本、摘要。现有分析、开发和审查角色的技能内容及行为不变。

## 装配规则

- 初始化时检查定义编码与键一致、每个内置角色均有清单、清单内无重复且引用的技能存在；无技能可明确配置为空集合。检查失败则不能使用不完整的注册表。
- 复制目录和清单，防止调用方后续修改；按清单顺序生成方法指导，并沿用运行时技能版本、内容摘要和装配记录。
- 技能只是方法指导，不授予工具权限；角色能力、用户授权、任务范围和运行控制仍是独立约束。

## 范围

此期只整理服务端内置定义及组合方式，不接收用户或模型上传的技能，不提供在线发布、动态更新、多租户隔离或运行中热切换。增加角色仍需实现对应领域枚举、运行编排及经过验证的装配配置，不能仅添加一个清单就声称已支持新 Agent。
