# 按工具类型配置调用限额

任务可为受控工具类型分别设置 0—20 的调用上限，0 表示不能启动该工具。该限制与运行总工具次数、统一单工具上限、统一单 Agent 上限及角色单实例上限同时生效，不授予任何工具权限；未配置工具维持原限制。

策略以任务、工具枚举、版本和整数上限持久化，与任务创建同事务。工具使用次数统计本运行及恢复祖先的已启动调用，失败、取消与结果未知同样计数；恢复不会把工具总额度重置。达到统一单工具上限时优先报告统一限制，否则报告具体工具上限。

输入只允许已知工具和整数，拒绝未知／重复工具、小数、字符串及越界值。旧任务无策略时保持原行为。用户页面提供可选配置和运行详情展示，完整与精简报告记录工具限额；该能力只适用于当前单进程顺序执行，不提供并发原子预留或按工具费用计算。
