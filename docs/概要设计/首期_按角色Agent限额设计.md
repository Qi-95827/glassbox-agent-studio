# 按角色配置 Agent 调用限额

## 目标和规则

在运行总轮次、总工具次数、单工具上限和统一单 Agent 上限之外，任务可为 ANALYST、CODER、REVIEWER 分别设置每个实例的模型调用和工具调用上限。模型上限为 1—20 的整数，工具上限为 0—20 的整数；未设置的项不额外限制。统一单实例上限与角色上限同时生效，先触及哪个停止哪个；同时触及时优先报告统一单实例上限。角色上限不授予工具权限。

## 结构与执行

请求使用角色枚举到结构化限额的映射，拒绝未知或重复角色；验证后按任务保存版本为 1 的角色策略。旧任务无策略时保持原行为；恢复运行读取同一任务策略，新 Agent 实例按自身调用计数，运行总预算仍继承。每次模型或工具启动前根据数据库中本次实例的受控角色读取政策；找不到或不识别角色时拒绝执行。失败、取消、未知及重试只要启动过都计数。

策略与任务创建同事务；未知版本、错误角色或非法限额不能默认为无上限。页面提供可选配置并展示已生效的策略，完整和精简报告也记录受控的角色限额，停止原因区分角色限额与统一单实例限额。首期仍单进程顺序执行，不提供并发原子预留、角色跨实例累计总额、Token 或费用硬预算。

角色限额只接受明确字段和 JSON 整数，拒绝未知或重复字段、小数、字符串或溢出值，避免输入错误被静默转换；不改变其他请求字段的兼容行为。
