# 精简运行报告

完整 HTML 报告包含目标、模型回答、执行事件和可能的代码差异，适合本地查看，不能视为已脱敏。增加独立的精简视图：只输出系统枚举、数值统计、角色／工具限额和计划角色／状态，不包含任务目标、模型与工具内容、代码、文件路径、工作区、运行／Agent 标识和事件正文。

精简视图使用字段白名单直接生成，不先生成完整报告再做字符串替换。Token 数是本运行及恢复祖先的已报告用量，未知调用数单列；模型／工具记录数仅指本运行。下载为独立 HTML，使用严格内容安全策略和禁止缓存头。

统计结果和角色组合仍可能成为关联线索，该报告不是匿名化保证；分享前仍由用户检查。与完整报告一样，它是查询时的记录快照，不代表代码已验证或运行环境完整。
