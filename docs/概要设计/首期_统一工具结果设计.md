# 首期统一工具结果设计

> 2026-11-15 更新：原成功结果版本 1 已扩展为版本 2；明确可纠正的参数拒绝和版本冲突也返回结构化结果，详见 [工具可纠正错误设计](首期_工具可纠正错误设计.md)。其他未知异常仍终止执行。

现有三个 AgentScope 工具继续由框架注册和调用，新增共用工具调用包装器；服务端仍控制工具注册、单文件范围、写授权、预算和取消，模型输出不授予权限。

成功返回统一 JSON：`schemaVersion`、真实系统 `toolCallId`、系统内工具 `toolId`、工具 `toolVersion`、`status=SUCCEEDED`、`effect`（只读或写入）、`startedAt`、`finishedAt`、`durationMs` 与按工具确定结构的 `data`。模拟检查数据为文本，读取数据为原有文件内容及摘要，写入数据仅为新摘要；版本 `1` 标识项目包装契约，不代表 AgentScope 的版本。工具调用记录保存安全摘要而非文件正文，事件仅模拟工具会记录其模拟输出。

包装器在开始前调用统一预算／取消检查，取得真实调用 ID；完成后记录事件、调用结束和耗时。工具抛错时保留异常传播和既有停止逻辑，避免让 Agent 把失败当成功；本期失败不会向模型返回统一 JSON，失败及取消仍从调用记录读取。写操作异常不证明无副作用，现有本地实现尚无完整对账台账。工具结果中的内容仍是不可信数据，不能覆盖系统规则。

验收：模拟工具经 AgentScope 返回统一结构、调用 ID 关联数据库，读取／写入结果结构与范围正确，总预算和单工具预算不受绕过，异常仍导致实际失败或超限；同时验证原有模拟评测和工作区测试。真实 DeepSeek 对新格式的适应性需另行验证。
