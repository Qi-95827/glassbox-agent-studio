# 项目背景历史查看

项目背景的创建、修改和逻辑删除已有版本历史，但用户缺少查看入口。提供按工作区和记忆 ID 查询的只读历史，按版本倒序、通过版本号游标分页；服务端限定每页 1—50 条。查询包括已逻辑删除的记忆，但必须属于指定工作区，不存在或不属于该工作区统一返回未找到。

页面对当前有效记忆提供历史入口，列出版本、类别、状态、时间和当时的正文；按需加载更多。删除后当前列表不再展示该记忆，历史本身仍保留；知道 ID 时可通过接口查询。历史查看不自动恢复旧版本、不向 Agent 装配、不表示用户撤回已发送给模型的内容。历史含原文，仅适合当前本地可信环境，不提供租户授权、保留期限或物理擦除。
