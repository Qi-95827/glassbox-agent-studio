# 评测与运行统计首期详细设计

## 目标和边界

提供可重复的本地种子评测与单次运行统计，方便观察固定的 AgentScope 协作流程。种子集仅使用模拟模型及模拟工具，不读取密钥、不操作真实仓库、不调用外部服务；不能据此推断真实 Bug 修复质量。动态样本、版本对照、真实仓库独立裁判、多租户、Prometheus 与告警属于后续范围。

## 种子评测

固定 `LOCAL_AGENT_V1` 三个案例：正常协作（运行完成、两个步骤均完成且有工具事件）、工具失败（运行失败且有失败工具调用）、预算拒绝（运行超限且没有实际工具调用）。这些断言检查持久化事实，并保留关联运行与解释，不根据模型口述判定通过。案例固定预算、场景与模型，种子集编码在结果中留存，以便后续版本比较时区分条件。

批次状态为 `RUNNING`、`CANCELLING`、`CANCELLED`、`COMPLETED`、`FAILED`、`INTERRUPTED`；案例状态为 `PENDING`、`RUNNING`、`PASSED`、`FAILED`、`CANCELLED`、`INTERRUPTED`、`SKIPPED`。批次完成仅表示本次评测执行完毕，不等于所有案例通过；通过比例为 `PASSED / 案例总数`，未运行和未知都不计通过。每次只顺序执行有限样本，复用原运行的轮次、工具和时长限制，评测本身禁止并发启动多个批次，防止重复占用队列。取消先阻止新的样本调度，并向在途运行发出协作式取消；已结束的样本保留真实结果，没有启动的样本标为跳过。在途运行已抢先结束时保留它的真实结果，不编造取消。进程重启后未完成批次与案例标记中断，不自动重跑，以免重复动作。案例关联 runId 可进入原运行查看 Agent、工具、模型及事件证据。

## 运行统计

按一次运行和真实 Agent 实例计算模型调用数、工具调用数、可用耗时、已知输入／输出 Token 总量以及用量未知的调用数。已知用量总量为空表示没有可统计值，不将未知当作零；耗时只累加有记录的调用，另提供未知耗时数量。工具名称来源于实际工具调用，不由模型回答推测。此统计是当前数据库快照，不等于分布式 Trace、费用、百分位指标或 Prometheus 指标。

## 查询与验收

本地 API 提供启动评测、查看批次和案例，以及查询运行的 Agent 统计；工作台可查看评测结果并跳转案例运行。状态枚举在持久化和 API 使用稳定名称。自动化验证正常／失败／限额三个评测案例、不可并行、历史结果、未知用量、实例归属和进程中断处理。数据库事务保证单条状态更新；进程在创建子运行与绑定案例之间崩溃时，可能出现无法关联的运行，批次标记中断且不自动重试。
