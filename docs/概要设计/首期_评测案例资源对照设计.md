# 评测案例资源对照设计

## 目标与边界

在已有逐案例状态对照中，对基线和候选各自展示关联运行记录的模型调用数、工具调用数、输入／输出 Token 已知合计和未知调用数，以及已落终态运行的已记录耗时。通过状态与资源事实分开，不据此推断质量或优化归因；环境、代码和配置仍未完整锁定。

## 数据口径

从每个案例关联的运行和该运行实际 Agent 调用记录计算，不将其他运行或祖先调用自动合并；若案例没有关联运行则资源为空，关联运行缺失时返回不可用和运行 ID，不能默认为零。模型和工具数量为已启动记录数；Token 对有报告值的调用分别求和，完全无已知值为 null，另列未知次数，不把部分已知合计当完整总量。运行耗时来自已落终态运行保存的累计活跃时间，排队、暂停和停机时间不保证包含；进行中或中断状态的完整耗时为未知。费用、性能百分位和跨批次统计显著性当前不计算。

比较结果是查询时快照，样本、运行和调用分别读取，非跨表一致快照；两侧套件相同也不能证明模型／代码／环境一致。页面分别展示每侧资源，不自动计算提升百分比。验收覆盖正常模拟案例、未关联／缺失运行、未知 Token、进行中或中断耗时、运行隔离及历史状态对照不变。
