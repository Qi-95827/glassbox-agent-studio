# 首期运行 HTML 报告增强设计

静态 HTML 报告汇总生成时可获取的任务、运行、计划节点、实际 Agent／技能、结构化交接、模型／工具调用、预算、事件和检查点；已知与未知 Token、未发生调用、复用历史分析节点和实际调用分开表示。任务约束和验收条件显示为用户提出的待验证要求，不作为自动通过证明。工作区差异、测试和审批为报告生成时可读取的工作区历史，不默认视为与运行完全一致。

报告不执行脚本；所有用户、模型、工具及仓库来源文本均经过 HTML 转义，响应继续使用限制脚本的 CSP 和下载方式。报告可能包含目标、约束、模型摘要、工具事件和代码差异，当前没有自动脱敏或访问控制，分享前需用户检查。生成期间各查询并非一个跨 Git／数据库事务的一致性快照，状态可能继续变化；无法读取工作区时明确显示不可用。

验收覆盖两个／三个 Agent 和技能、计划复用、已知／未知用量、交接和事件引用、特殊字符及脚本注入转义、无工作区与不可用工作区、报告下载 CSP；报告不得声称未执行的测试、用户批准或 Git 合并已发生。
