# 首期运行终态保护设计

已完成、失败、取消、超限、阻塞和中断的运行均为本次运行终态；异步回调或旧执行者不得把它们改回运行中。运行更新采用数据库条件更新，只允许从 `PENDING`、`RUNNING`、`PAUSED` 更新，条件不成立时报错并保持原记录；模型和工具调用已有仅从 `RUNNING` 结束的条件更新。恢复或重跑创建新运行，不修改原运行终态。

同一进程中，对同一运行的模型／工具调用槽位开始与结束加锁，避免取消路径和返回回调并发清理时重复记录。此保护不提供跨实例租约或 fencing；在途外部写操作已经开始时，取消不保证撤回，晚到结果与副作用核对仍需独立台账。验收覆盖终态不能被更新、调用终态不被晚到回调覆盖、正常运行／暂停／取消／恢复回归。
