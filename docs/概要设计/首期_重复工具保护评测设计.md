# 重复工具调用保护评测

## 样本和预期

新增使用模拟模型的重复调用样本：模型轮次预算为 8、工具总预算为 5、同种工具预算为 5、连续相同调用阈值为 2。模拟模型连续请求同一工具；预期系统在两次实际调用后阻止第三次，运行状态为 LIMITED，停止原因为 REPEATED_TOOL_LIMIT。逐项断言运行状态、结构化停止原因和已启动工具次数，避免仅凭停止状态误判为保护生效。

## 定义版本与兼容

种子套件变更为 V2，断言版本递增，并在定义快照中保存各案例的模型轮次与连续相同工具阈值。已有 V1 批次和结果保持不变；不同套件或快照的批次不可判定结果变化，缺失案例不伪造。仍使用模拟模型和工具，不产生外部副作用。

## 范围

该样本只测试相同输入的连续重复调用，不证明语义相近但输入不同的循环能被发现，也不能替代真实模型、不同工具和并发场景的评测。
