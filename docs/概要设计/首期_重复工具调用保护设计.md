# 首期重复工具调用保护设计

任务可选设置“同一工具及相同输入允许连续调用的最大次数”，范围 1—20；默认关闭以避免阻止可能有意义的重复读取。每次工具开始前，由服务端对工具类型、授权工作区、文件范围及实际参数计算带长度边界的 SHA-256 指纹；不保存参数正文或文件内容。相同工具、相同指纹的连续已启动调用达到设置次数时，拒绝新增调用并以 `LIMITED` 结束运行。不同工具或输入会重置连续计数；失败和输入拒绝只要已启动也计数。

指纹记录以数据库自增顺序保存并关联真实工具调用，与调用记录同事务写入；恢复运行追溯其祖先的指纹序列，不能通过切换 Agent 或恢复清零。旧运行无指纹记录，不凭历史名称猜测参数；启用此功能的运行才参与该保护。SHA-256 只是比较用摘要，不是加密或访问授权，低熵参数仍有被猜测风险，接口和页面不展示摘要。

本功能仅识别连续、完全相同的调用，并不判断返回结果是否发生变化，也不能识别换参数但无进展的语义循环。它可能阻止有意义的重复读取，因此需要用户明确启用；允许调整阈值或关闭。当前单进程执行，不提供多实例并发原子限额或跨服务事务。验收覆盖正常单次、启用后的重复阻断、不同输入重置、预算计数、跨恢复累计和默认关闭；使用受控模拟模型重复请求，不依赖模型自述。
