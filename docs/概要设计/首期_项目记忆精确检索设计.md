# 项目记忆精确检索设计

## 目标与边界

在现有用户确认的本地工作区记忆上提供可视化查询，按工作区、可选类别和内容子串筛选。此功能服务用户查找和管理记忆，不改变 Agent 的自动上下文选择；不声称是语义检索、向量检索、模型推理或多租户隔离。只返回当前有效版本，历史或已删除版本不出现在结果中。

## 输入输出与规则

`GET /api/workspaces/{workspaceId}/memories/search` 接收可选 `q`、`category`、`limit`，返回原有 `MemoryRecord` 列表。关键词去除首尾空白，最多 100 字；空关键词表示不筛选文本。类别使用已有枚举，非法值由接口拒绝；限制默认为 20，允许 1—20。关键词及内容使用 Unicode NFKC 和与语言环境无关的大小写转换，然后做字面子串匹配，因此 `%` 和 `_` 不作为通配符；同分按原有更新时间降序及 ID 顺序。无匹配返回空数组，不自动降级为全量结果。每次从数据库读取工作区有效记录，不缓存内容；目前每工作区最多 20 条，故内存过滤有明确上界。

## 安全、一致性和验证

先校验工作区存在，再按工作区和有效状态读权威库；不得因无匹配跨工作区搜索。编辑、删除后下一次检索读取当前状态；已发给模型或历史记录的内容不能撤回。内容是用户提供的不可信数据，搜索结果不改变工具权限。当前本机服务没有用户／租户认证，工作区过滤不能替代权限隔离。验收涵盖大小写与全角归一化、字面通配符、类别、无匹配、版本更新和软删除、不同工作区、非法长度和条数，以及原先记忆列表和任务装配不受影响。
