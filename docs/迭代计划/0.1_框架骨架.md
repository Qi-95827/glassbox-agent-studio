# 0.1：可运行的 Agent 框架骨架

本期概要设计：[0.1 Agent 框架概要设计](../概要设计/0.1_Agent框架概要设计.md)。

## 目标

用不依赖真实模型和危险外部工具的示例任务，验证各模块可以贯通，建立能观察、能控制、能保存与恢复的最小基础。

## 计划功能

- 创建个人示例任务和一次运行，记录目标、身份占位、状态与关联标识。
- 按角色配置启动一个 Agent；由简单协调者进行一次子任务委派并记录结构化结果。
- 提供模拟模型、无外部副作用的模拟工具和基本上下文；工具调用必须产生真实的执行事件。
- 设置轮次、工具次数和时间限制，支持基本取消、异常和可理解的停止原因。
- 在明确的安全节点保存内部状态并重启恢复，持久记录任务、事件和结果；无法读取或不完整的快照不得当成有效快照。
- 用户页面可创建示例任务、查看真实状态、Agent／工具时间线和结果；提供基础健康／运行概况入口。
- 提供可重复的示例、基础测试、启动说明和未实现能力说明。

## 依赖与边界

具体 Java、构建工具、AgentScope Java 版本和前端技术在实现前核验并确定。0.1 不接真实仓库写入、不调用危险命令，不声称实现真实 Token 计费、完整权限隔离或分布式一致性。快照独立于 Git；只保证本期明确测试过的模拟恢复场景。

## 验收

1. 按文档在干净环境启动，无模型凭据即可完成一次示例任务并在刷新后查看记录。
2. 任务、运行、Agent、工具及事件可关联；页面数据来自实际执行。
3. 超限、模拟错误、取消分别得到正确状态；中断后从有效快照恢复，损坏快照被拒绝。
4. 关键正常／失败／恢复场景可重复验证；文档准确列出未完成项。

## 暂不完成

真实模型、Git 工作区、模拟 Bug、完整后台、长期记忆、多租户和生产级恢复，按后续版本推进。
