# 0.2：Agent 能力与协作基础

## 目标

把 0.1 的示例抽象成可组合的 Agent 角色与能力，让不同角色能用结构化结果交接，并提供受控的真实模型接入。

## 计划功能

- 定义角色职责、能力配置、运行实例、结构化输入和结果；提供至少两个不同职责的示例角色。
- 实现顺序委派与交接，包含目标、约束、结果、失败和证据引用；区分事实、模型推断与未验证内容。
- 支持按任务组装必要上下文和工具；提供 Skill 的基础描述／版本位置，未实现的能力明确禁用。
- 真实模型作为可配置适配器，保留模拟模式；说明发送的数据范围、超时、取消、错误及可获得的用量。
- 完善轮次、工具调用、时间和可获取用量的限制，记录重试与停止原因；不得用伪造用量补零。
- 扩展角色、交接、模型失败、预算和上下文相关测试。

## 依赖与边界

依赖 0.1 的事件、控制和恢复基础；接入真实模型前先明确用户授权和敏感数据范围。多角色以顺序协作为主，不承诺并行一致性、长期记忆或模型结果正确。

## 验收

角色能接收不同职责并传递结构化结果；用户可追溯实际调用与交接。模拟模式可重复运行；真实模型异常、取消与缺失用量被正确呈现。
