# 0.5：用户工作台与人工控制

## 目标

让个人用户理解、控制和审查一次开发任务，形成可独立阅读的 HTML 报告。

任务详情优先建设可实时跟进的执行流程图。以实际计划与调用记录定位当前节点、已执行动作、阻塞和可用控制，契约及验收见[任务执行流程可视化与接口设计](../概要设计/任务执行流程可视化与接口设计.md)。

## 计划功能

- 任务列表、创建及详情；显示目标、计划、子任务、Agent 调用关系和时间线。
- 查看工具、测试、代码差异、证据、用量、耗时和未验证项；标识事实、推断和结果未知。
- 用户补充信息、调整计划、暂停／继续／取消、查看受影响状态并决定批准或拒绝。
- 审批关联具体范围与版本；目标分支或审批后代码变化时检查是否需要重新审查。
- 支持用户接手修改后交还任务，并检查工作区变化及旧证据的有效性。
- 生成脱敏、受权限控制且安全呈现不可信文本的 HTML 报告；明确报告快照与可恢复状态不同。

## 依赖与边界

依赖 0.4 的业务证据与已有事件；任务由个人控制，不引入多人实时协作。真实动作以既有权限与审批约束为准。

## 验收

用户能完成一次任务并在界面追溯实际 Agent、工具及测试；审批拒绝、取消、中途修改与过期证据均得到可理解的处理；报告内容与记录一致。
