# 0.7：Checkpoint 与可靠恢复深化

## 目标

在已有基本保存恢复上，增强长时间任务与异常情况下的状态一致性和恢复能力。

## 计划功能

- 按周期和关键节点生成内部 Checkpoint，记录版本、完整性、状态、事件位置和可恢复条件。
- 覆盖 Agent 交接、待处理消息、预算、审批状态与进行中调用；防止同一运行被并发恢复。
- 对调用结果未知的外部动作进行状态核对、幂等保护或请求人工处理；不能盲目重试。
- 检查权限、审批、目标、工具版本及工作区是否变化；从历史点恢复时保留原运行与现实中已发生的动作。
- 独立规划工作区未提交文件的保护和恢复；可关联 Git 引用，但不要求每个 Checkpoint 产生提交。
- 提供恢复状态页面与故障演练：快照写入中断、调用中断、外部成功但本地未记录、并发恢复等。

## 依赖与边界

依赖事件、持久状态及已接入工具的副作用信息。借鉴一致快照思想，但不能声称自动得到端到端恰好一次；不可核对动作应阻塞或转人工。

## 验收

对明确支持的故障点重复演练，恢复结果、预算及证据符合规则；损坏快照、过期审批、冲突恢复和未知外部结果不会被静默忽略。
