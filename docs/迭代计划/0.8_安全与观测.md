# 0.8：安全、预算与观测深化

## 目标

在各真实能力已经具备最低保护的前提下，系统化增强安全治理、资源控制和运行监控。

## 计划功能

- 深化身份、仓库／路径／工具授权、隔离、敏感信息处理和高风险审批；验证提示注入和越权场景。
- 统一时间、调用次数、Token、费用估算与并发限制；并发扣减与未知用量的显示规则可验证。
- 增强审计、日志、事件与链路关联；管理者操作有记录并受权限约束。
- 建立服务、任务、Agent、模型、工具、Checkpoint 和依赖的指标与必要告警，支持从异常定位到具体运行。
- 验证现有 Prometheus／Grafana 环境并按需复用现有实例、3000 端口及独立看板；工作台使用其他端口。
- 在评测中加入恶意仓库内容、预算耗尽、依赖失效及恢复等案例。

## 依赖与边界

此期是深化而非首次考虑安全：此前真实仓库和命令开放前已有对应基础保护。具体告警阈值根据实际基线确定；共享进程资源、模型未知用量不应被虚假精确归因。

## 验收

越权、注入、超限及关键告警场景可验证；数据脱敏与授权有效；看板指标与真实事件一致，不能因为图表存在就宣称质量可靠。
