# 0.9：集成回归与发布候选

## 目标

将前述能力组合为可供个人试用的候选版本，集中修复阻碍交付的问题。

## 计划功能

- 从环境自检、项目接入到模拟 Bug 修复、审查、用户决定、报告及反馈完成端到端回归。
- 覆盖暂停／取消、不可复现、测试失败、预算耗尽、权限失效、分支变化、崩溃恢复和异常外部状态。
- 完善安装与升级说明、示例、故障排查、备份恢复、数据保留与清理说明。
- 汇总评测、成本、性能与安全结果，修复关键缺陷，记录已知限制与未达标项目。
- 明确发布候选的版本、Git 标签策略和回退方式；评测不通过时推迟发布或缩小承诺范围。

## 依赖与边界

依赖 0.1–0.8 对本期闭环必要能力的实际完成；不以版本号代替验证，不默认包含共享多租户平台。

## 验收

可按说明在目标环境独立部署并重复完成闭环；关键失败和恢复案例有记录；剩余问题不会使文档中的安全与交付承诺失真。
