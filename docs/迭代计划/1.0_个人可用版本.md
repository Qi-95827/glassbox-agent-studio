# 1.0：个人开发者可用版本

## 目标

交付一个边界清晰、可安装、可观察、可控制并经过评测的个人代码开发 Agent。

## 计划功能

- 支持个人用户接入授权仓库，以模拟 Bug 进入分析、复现、修复、测试、审查和交付流程；其他入口以实际完成的范围为准。
- Agent 角色与模块可按已验证的配置组合；任务、Agent、模型、工具、交接和证据可追溯。
- 用户工作台支持关键控制、预算、差异审查、人工决策与 HTML 报告。
- 提供与已支持能力相匹配的访问控制、隔离、取消、内部状态恢复、外部副作用核对、观测和基础平台管理。
- 提供可重复评测、安装运维、自检、已知限制和版本变更说明。

## 依赖与边界

以 0.9 的集成与验收结果为准。用户决定是否合并；不可复现、测试未通过或缺证据必须明确显示。1.0 不承诺所有任务自动成功，不要求支持多人共同操作同一任务或完整共享多租户部署。

## 验收

典型个人用户能按文档完成授权项目的完整模拟 Bug 闭环；安全、恢复、预算、证据与评测达到该版本事先确定的可测标准；未支持的功能和已知风险清楚可见。
