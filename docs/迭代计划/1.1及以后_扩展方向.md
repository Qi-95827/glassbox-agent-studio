# 1.1 及以后：候选扩展方向

以下为候选，并非固定顺序或已经承诺的 1.1、1.2 范围。每次迭代应按真实使用、依赖、安全和评测结果重新确定。

- 接入真实 Bug／Issue 平台，处理授权、重复事件、反馈及外部副作用。
- 扩展需求、概要设计、测试与审查等入口；支持更多用户配置与任务模板。
- 改进长期记忆、版本冲突、检索与删除，按实际规模评估向量检索。
- 扩展 Agent 角色、并行协作和冲突处理，评测质量、成本及信息损失。
- 加入更多模型供应商、工具与 Skill，完善版本发布、灰度和回退。
- 按需要提供共享部署、多用户／多租户隔离、配额、组织管理和运营后台；仍不自动要求多人共同控制同一任务。
- 增强通知、报告、运行比较、用户反馈和评测中心。
- 扩展资源容量规划、备份恢复、告警处置和运维能力。

## 监控与可观测指标细化（待办）

**状态：已登记需求，待排期实现。** 当前「监控与告警」仅展示全局汇总次数与总 Token / 总耗时，后续按以下四个维度做细化展示与下钻：

1. **按任务 / 运行维度明细表**：
   - 展示每条任务/运行的：模型调用次数、工具调用次数（成功 / 失败 / 被网关拦截）、输入 Token、输出 Token、总耗时、估算/结算费用，支持按耗时、Token 或调用次数排序，点击直达对应运行详情。
2. **按模型维度统计**：
   - 按 `modelName`（如 `deepseek-flash`、`mock`）分组统计：总调用次数、成功率 / 失败率 / 限流次数、平均耗时与 P95 耗时、输入/输出 Token 汇总、累计费用估算。
3. **按工具维度统计**：
   - 按 `toolName`（如 `read_authorized_file`、`write_authorized_file`、`search_authorized_files`）分组统计：调用次数、成功/拒绝/失败占比、平均耗时、ToolGateway 各安检门拦截 Top 原因。
4. **返回状态与异常分布**：
   - 统计模型返回类型（纯文本回复 vs 触发 `tool_calls`）及工具返回状态码分布，并同步暴露为 Prometheus 指标标签以便接入 Grafana 看板。

新能力在开放前需完成相应权限、隔离、数据处理、评测和恢复规则；不能因预留目录就视为能力可用。

## Docker MySQL 适配

**状态：待办，未排期。** 工作台当前默认使用 H2 文件库。后续增加 Docker MySQL 配置，先在独立空库验证，再决定是否迁移现有历史数据。

- 增加 MySQL Connector/J 和独立 Spring Boot 配置。连接地址、账号和密码通过环境变量提供。
- 提供 MySQL 版建表及升级脚本，核对自增主键、长文本、字符集、索引和约束。适配环境自检的数据库目录查询，复用现有 Spring Data JPA Repository。
- 验收时使用真实 Docker MySQL，验证空库初始化、重复启动、中文内容读写、账号与私有 Agent 归属、候选计划创建和确认、任务运行、事件分页及回滚。确认容器重启后数据仍可读取。
- 如需保留 H2 的账号、任务、运行、事件和私有组件版本，另做数据迁移。先备份 H2 并用副本演练，核对记录数、关联、关键内容和自增序列，记录切换及回退步骤。
